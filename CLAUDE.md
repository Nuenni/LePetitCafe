# LePetitCafe — Claude Instructions

## Workflow

**"update"** bedeutet immer:
1. Alle Änderungen committen
2. Auf den aktiven Branch pushen
3. Pull Request erstellen (falls noch keiner offen)
4. PR mergen

Kein Nachfragen — einfach durchziehen.

## Projekt

Kassenbon-Drucker für Kinder. Raspberry Pi Zero 2 W + WLAN-Thermodrucker (ESC/POS) + 3 Arcade-Knöpfe.

- **Bon-Generatoren:** `receipts/` (DE + EN)
- **Simulator:** `simulator.html` (DE), `simulator_en.html` (EN)
- **Demo live:** https://nuenni.github.io/LePetitCafe/
- **Hardware-Doku:** README.md
